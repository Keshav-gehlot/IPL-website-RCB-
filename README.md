# Royal Challengers Bangalore (RCB) Fan Website

A modern, responsive website for Royal Challengers Bangalore fans, featuring news, match updates, player statistics, and a fan community.

## Features

- Responsive design that works on all devices
- Modern bento grid layout for content presentation
- Real-time match updates and statistics
- Player profiles and team information
- News and media section
- Fan zone community
- Interactive match schedule
- Contact form for fan inquiries

## Technologies Used

- HTML5
- CSS3 (with modern features like Grid, Flexbox, and CSS Variables)
- JavaScript (ES6+)
- Font Awesome for icons
- Google Fonts
- Intersection Observer API for scroll animations
- Lazy loading for images

## Project Structure

```
├── index.html              # Homepage
├── team.html              # Team and player profiles
├── matches.html           # Match schedule and results
├── stats.html            # Player and team statistics
├── news.html             # News and media section
├── fanzone.html          # Fan community section
├── contact.html          # Contact form
├── styles/
│   ├── main.css          # Main stylesheet
│   ├── bento.css         # Bento grid styles
│   └── animations.css    # Animation styles
├── scripts/
│   ├── main.js           # Main JavaScript file
│   └── features.js       # Feature-specific JavaScript
└── images/               # Image assets
```

## Setup and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/rcb-fan-website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd rcb-fan-website
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   ```
